# Poster face references

This is the living reference library for facial design in Cello Cool Club posters.

- The current images in this folder are the source of truth for face shape, eyes, noses, mouths, profiles, age, and expression.
- Add, replace, crop, recolor, or remove images to evolve the facial style.
- Current filesystem contents always override old prompts and metadata.
- These references define a design grammar, not recurring character identities.
- The main `assets/poster-references/` folder remains the source of truth for the complete poster composition, line, texture, palette, and framing.

The initial six crops come from approved poster 098, image 1 of the 098-102 batch.
