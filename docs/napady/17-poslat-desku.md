# Poslat desku — formy doručení

Zásada: **neposílá se odkaz, posílá se objekt.** Každý kanál dostane formu,
která v něm vypadá jako dárek.

| Kanál | Forma | Náklad |
|---|---|---|
| **WhatsApp/Telegram** | share intent s [věnovací URL](16-venovani-a-na-prani.md) + OG; ještě lépe **20s teaser MP4** (B2!) — přehraje se v chatu inline | zero, pipeline existuje |
| **E-mail** | věnovací URL v hezké šabloně (newsletter D1) | zero |
| **Pohlednice od Claire** | fyzická karta poštou: **sleeve obálka jako obal 45s singlu**, věnování „rukopisem Claire“, voskové razítko CCC | ~8–12 € prodejní produkt |
| **Dárková limitka** | [lithophane](13-3d-tisk-limitky.md) se jménem vyraženým do rámečku | ~25–35 € |

- **Teaser s věnováním:** drawtext overlay „Pro Janu“ = jeden ffmpeg filtr,
  ale per-věnování generování chce server. Fáze 1: ruční služba pro členy;
  fáze 2: Worker fronta.
- **Obálka = sleeve:** i běžný deck může mít dokoupitelné sleeve obálky —
  každá karta poslatelná poštou jako singl. Crowdfunding add-on.
- **Telegram/WhatsApp kanál klubu:** v neděli hitparáda + týdenní výzva
  „komu dnes pošleš desku?“ — sdílení jako rituál.

**Věnování je akvizice maskovaná jako něha.** Nikdo neposílá reklamu —
posílá dárek.
