# Inbox

Paste-ready formatted source texts belong here before they become structured card records.

Recommended file naming:

```text
YYYY-MM-DD-short-title.md
```

Example:

```text
2026-06-05-the-lantern.md
```

Workflow:

1. Save the source text here exactly as received.
2. Convert it into a structured card record in `data/cards.json`.
3. Keep the inbox file as the original source.
4. Add image and Suno prompts after review.

Do not edit the original source text unless the user explicitly asks for cleanup.
