# Vizuální novela — synchronizovaný text

Když se deska točí, karta může **vyprávět**.

- **Synchronizované verše:** během přehrávání naskakují řádky básně v rytmu
  písně (kinetická typografie v paletě sezóny). Claire scéna v pozadí
  s jemným parallax/Ken Burns pohybem — žádné video, jen CSS/JS.
- **Jazyky:** přepínač FR/CZ/EN přepíná běžící text (synergie s C6).
  „Učíš se francouzsky s Claire“ = vedlejší produkt zdarma — a argument
  pro Suzuki rodiče.
- **Časování — LRC formát** (`[mm:ss.xx] řádek`). Suno časy nedává → mini
  nástroj v admin panelu: pustíš píseň, ťukáš Enter na každém řádku →
  engine uloží `.lrc`. Otagovat píseň = 3 minuty. Pole `lyricsTimed`,
  exportér vydá LRC jako veřejný asset.

## Řetězová hodnota — jeden LRC pohání:
1. novelu na stránce karty (delší návštěvy, sdílení),
2. **titulkované teasery/Shorts** (B2 + drawtext — lidé koukají bez zvuku),
3. karaoke mód pro kids deck (Suzuki děti zpívají s Claire),
4. lyrics video formát pro YouTube album.
